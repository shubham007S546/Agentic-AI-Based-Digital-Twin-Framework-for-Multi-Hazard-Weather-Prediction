How It Works
1

Image Upload

Farmer uploads a leaf photo. Frontend sends base64 image to FastAPI /disease/predict endpoint.

2

ResNet9 Inference

Model preprocesses to 256×256 RGB, runs forward pass, returns top-5 class probabilities as XAI confidence scores.

3

Recommendation Engine

Backend maps predicted class to disease metadata: pathogen, recovery time, pesticide name, approx cost per spray.

4

Cost Estimation

Farm parameters sent to /cost/predict. Random Forest (300 trees) predicts total production cost with itemized breakdown.

5

Charts & Insights

Frontend renders XAI confidence bars, cost donut, monthly cashflow, and crop benchmark charts via Chart.js.

How the Hybrid RAG Pipeline Works
1

Query Rewriting

ConversationMemory provides chat history. QueryRewriter (Groq LLM) resolves pronouns and context: "it" → "the cloudburst formation process in the Himalayan region".

2

Dual Retrieval — FAISS + BM25

FAISS searches the MiniLM-L6-v2 embedding space (semantic similarity). BM25 does exact keyword matching over the same chunks. Both return a candidate pool (default 10 each).

3

Reciprocal Rank Fusion (RRF)

Merges FAISS and BM25 results using RRF formula: score = Σ 1/(k + rank). This combines the strengths of both semantic and lexical matching. k=60 by default.

4

Cross-Encoder Reranking

Top RRF candidates are scored by a Cross-Encoder (query-document pair scoring). This is more accurate than bi-encoders because it sees both texts simultaneously. Only top_k (4) survive.

5

LLM Answer Generation

RAGPrompt assembles the final context from top_k chunks + conversation history + original question. Groq generates a grounded answer with source citations.
